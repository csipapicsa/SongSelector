## VirusTotal did not run on the 1.5.0 release

- The key is set (environment `VIRUSTOTAL_API_KEY`, 2026-11-23) and runs by hand worked, but from `release.yml` the
  scan logged "no key": a reusable workflow gets secrets only when the caller passes them. Fix: `secrets: inherit` on
  the `virustotal` job. 1.5.0 scanned by hand afterwards (`gh workflow run virustotal.yml -f tag=v1.5.0 -f update_notes=true`).

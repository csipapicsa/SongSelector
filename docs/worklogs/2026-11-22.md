## AllMusicCaps CLAP: notebook, first numbers, ONNX probe

User: "Can we have a notebook to try it out?" (MTG's music-trained CLAP, desk note of 2026-11-21), and later: would
an ONNX export for the app be hard?

- **Setup:** `amclap==0.1.0` installed into the research venv `.research_cache\venv-clap` (torch 2.7.1+cu118 kept;
  the venv gets sentence-transformers 5.1.2 because amclap pins < 5.2, the system Python keeps 5.6). Both variants
  downloaded to `.research_cache\hf`.
- **Code:** `AmClap` class (`amc-all-layers`, `amc-te-sigreg`) in the shared model interface
  `docs/research/experiments/clap/benchmark_cpu.py`, so `extract_embeddings.py --models amc-all-layers amc-te-sigreg`
  embeds the test set (every 10 s window at 24 kHz). 1,400 of 1,408 tracks in ~44 min on the GPU, 8 unreadable files.
- **Notebook:** `docs/research/experiments/clap/allmusiccaps.ipynb` (committed without outputs, like
  `text_search.ipynb`): side-by-side search of the four models, P@10 and average precision per genre tag, the
  best-matching 10 s of a track, zero-shot tags for any file. Executed end to end (CPU and GPU) before committing.
- **Checks:** no collapse (text cosines spread), the trained text encoder of `te_trained_sigreg` really loads (weights
  equal the checkpoint, differ from stock mpnet). Correction to yesterday's note: "all layers" is a plain mean of the
  12 OMAR-RQ layers, not a learned weighting.
- **Result** (990 common tracks, 744 tagged, 27 prompts written before any result): mean AP `all_layers` 0.328,
  `te_trained_sigreg` 0.285, LAION light 0.214, MS 2023 0.203, chance 0.143. `all_layers` - LAION +0.09 to +0.15
  (bootstrap over tracks), better on 22 of 27 prompts. Drum and bass AP 0.90 vs LAION 0.41. LAION still wins electro
  and (narrowly) downtempo. Results JSON: `docs/research/experiments/results/2026-11-22_allmusiccaps_genre_ap.json`.
- **ONNX probe** (scratch script, not committed): both towers export with the TorchScript exporter (opset 17) on the
  first try, dynamic batch; onnxruntime matches PyTorch (cosine 1.000000). Audio 296 MB, 217 ms per 10 s window on
  4 CPU threads; text 437 MB, 20 ms per query; tokenizer has a `tokenizer.json` for the `tokenizers` library.

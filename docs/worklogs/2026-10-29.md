# Worklog 2026-10-29

## 1. Playlist gaps, track counts, star ratings, more closest matches with chosen columns (4.17.0)

Requests (chat, two screenshots): the playlist shows empty columns without names; show how many
tracks are selected and, after filtering, how many the List view shows; choose the columns of the
closest-matches list on the map; ratings as stars instead of integers; list more closest matches,
not only the top 15.

- **Playlist gaps:** reproduced on a copy of the user's settings and library (`dist/` copied to the
  scratchpad, live files untouched) by printing `sectionPosition` per column: every hidden column
  had size 0 but still took 104 px, e.g. Camelot started at 382 px after Title ended at 70 px.
  Cause: since 4.15.0 `setSectionResizeMode(Interactive)` runs *after* `setColumnHidden`, and Qt
  then keeps the hidden sections' old width. Fixed by setting the mode first. The library list never
  set a mode, so it was not affected. Regression test: hidden columns between Title and Camelot,
  Camelot starts where Title ends.
- **Counts:** a label in the tab bar corner (*1,234 of 3,651 tracks, 3 selected*) and one under the
  playlist (*28 tracks, 2 selected*). Selected rows hidden by a search are not counted. Updated
  from the trees' selection and row signals through a 0 ms single-shot timer, because loading the
  library inserts thousands of rows one by one; `filter_items` also restarts it (hiding rows emits
  no model signal).
- **Stars:** `StarRatingDelegate` only changes the displayed text; the cell keeps the number, so the
  numeric sort, the text search ("5") and Advanced Search (`at least 4`) are unchanged. 0 is
  Traktor's "unrated" and stays blank (also left out of the map details, like colour 0).
- **Closest matches:** count spin box *List the N closest* (default 50, 5-2,000, saved as
  `Map match count`). Only the 15 most similar get a cyan ring on the map, otherwise 50+ rings
  cover it. Columns: Similarity, Mix, then all library columns (`MATCH_COLUMNS`, so Artist/Title
  keep indices 2/3); right-click the header to toggle, saved as `Map match columns`. Colour columns
  use the dot delegate, ratings the star delegate; numeric columns sort as numbers.

Verification: 135 tests + 192 table subtests (1 skipped: needs the real model); exe 4.17.0 passes
release verification (embedding step skipped: no model path set). Rendered
screenshots of the real data (offscreen, `QT_QPA_FONTDIR=C:/Windows/Fonts`): playlist without gaps
and with stars, both counts, map panel with 50 matches.

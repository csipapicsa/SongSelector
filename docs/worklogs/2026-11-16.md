# 2026-11-16

## 1.1.3: model coverage on switch, window stretch, "Describe a sound" bar (branch `fix/model-coverage-and-ui`)

User report after testing 1.1.2 (three bugs):

1. **Switching to LAION CLAP did not check what was analysed.** The bar's model choice only re-ran the search, and
   *Similarity model* only printed "not analysing, switch it on". A model that was off (or never switched on) stayed
   empty. Asked for: check each model's embeddings at startup; when switching between the CLAP models, analyse the
   missing tracks.
   - `EmbeddingStore.keys()`: analysed / failed path_keys, no blobs read.
   - `MainWindow.model_coverage()`: counts only tracks in the library (`store.counts()` also counted removed tracks,
     so `analysis_coverage` could overstate; it now uses the same intersection).
   - `ensure_models_analysed()`: called when the bar's model, the search window's model or the similarity model
     changes, and at startup for the models in use. Missing tracks -> switch the model on, restart the analysis
     (cached tracks are skipped per model by `run_analysis`), status line says "X has analysed a of b tracks;
     analysing the other c". Paused analysis or missing model files: says so, starts nothing.
   - Menus show "N of M tracks" per model; the progress tooltip lists every model. When the analysis reports all
     tracks done, coverage is re-checked: a model that failed to load shows as "not analysed: ..." instead of
     "up to date".
   - Interpretation note: models that are switched on keep analysing in the background as before; startup does not
     stop that. Only the "fill the gaps of the chosen model" part is new.
2. **Window stretched and could not be narrowed.** Cause: QLabel's minimum width is its whole text. The status line
   and the analysis progress (permanent status-bar widgets), and the bar above the List, raised the window's minimum
   width with long messages (prompts, file names). Also an editable QComboBox with the default size policy takes the
   longest item as its minimum, so a long saved prompt did the same. Fix: `ui/elided_label.py` (small minimum,
   elides with "...", full text + details in the tooltip); description combo uses
   `AdjustToMinimumContentsLengthWithIcon`. Kept stretch 0 on the status-bar labels so `showMessage()` texts still
   have room.
3. **"Sounds like:" renamed to "Describe a sound:"**, tooltip and placeholder say it is free text (AI / CLAP). First
   dropdown entry `NO_DESCRIPTION` ("no search: show all tracks") clears the search; Enter in an empty field too. It
   cannot be saved or deleted as a prompt.

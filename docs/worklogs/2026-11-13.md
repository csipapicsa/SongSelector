# 2026-11-13

## Rename to SongSelector, README for a public audience (branch `rename/songselector`)

Goal: the repo is linked from the developer's CV, but the README still said "Traktor Key Calculator" and described
the early key-calculator tool, and nobody outside could get the embedding model. Followed the backlog's rename plan
(item from 2026-11-05).

- **Package and build:** `traktor_key_calculator` → `songselector` (`git mv`, history kept), main window class
  `TraktorKeyCalculator` → `MainWindow`, spec and exe `SongSelector[-<version>].exe`; `build.ps1`,
  `verify_release.ps1`, `release.yml` follow. Test variables `TKC_*` → `SONGSELECTOR_*`.
- **Kept:** everything that means Native Instruments' Traktor (`traktor_sync.py`, `traktor_collection.py`, "Traktor
  Playlists", `TRAKTOR_SOURCE`, ...). History files, old worklogs and the pre-1.0 changelog stay as written.
- **User data must survive:**
  - New `env.py`: `getenv(NAME)` reads `SONGSELECTOR_<NAME>`, else the old `TRAKTOR_<NAME>`. An empty new value
    counts as set (`SONGSELECTOR_EMBEDDING_MODEL=` must switch the default off, not fall back). Fallback to be removed
    after 1.1 (backlog).
  - Settings file `SpotNextTrack_settings.json` → `SongSelector_settings.json`. `config.migrate_legacy_settings()`
    copies it once and renames the old file to `.bak`. Renaming (not leaving it) matters: "reset settings" deletes
    the new file, and a left-over old file would otherwise be migrated again and undo the reset.
  - `~/.songselector`, falling back to `~/.traktor_key_calculator` if only that exists (pip installs only).
  - New `tests/test_rename_migration.py` (6 tests).
- **Model export:** `scripts/export_cnn14_onnx.py` downloads the PANNs checkpoint from Zenodo, checks SHA-256
  (`0dc499e4...`), exports with the names the app uses (`audio` → `clipwise_output`, `embedding`, dynamic batch,
  opset 17) and compares with PyTorch (2.4e-06). Against the existing model through the app's `Cnn14Embedder` on
  DirectML, 8 chunks of a real track: max difference **0.0**, so existing `embeddings.sqlite` caches stay valid.
  Run in a throwaway venv (system torch 2.5.1 + panns-inference 0.1.1), not the app's `.venv`.
- **README** rewritten for someone arriving from the CV: what it does, features, an *Engineering* table (architecture,
  inference, testing, release verification, CI/CD, research with its negative result), install, model, usage,
  development. Claims checked against the code (import formats are MP3/WAV/FLAC; 8 harmonic mix types).
- Backlog: rename, linter, CI and real-file tests ticked; dead `test = 100` removed.

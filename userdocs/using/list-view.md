# The List view

The List is the main table: your library, or whatever the Browser or a search narrowed it to.

| Want to | How |
|---|---|
| Show or hide columns | Right-click a column header (*Speed change*, *Match*, *Group*, *Cover*…) |
| Cover art | *View → Cover art*: off, cropped to the row height, or square rows; 48 / 72 / 96 px |
| Keep the app above Traktor | *View → Always on top* |
| Dark or light | *View → Dark theme* |
| More room for the List | *View → Search bars* hides the rows above it (a search set before stays in force) |
| Edit artist, title, genre, comment | Right-click → *Edit track info…* (written back to the file) |
| Remove tracks from the list | Select, then Del. Files on disk are never deleted |
| Clean up | Right-click → *Remove missing files from the list*, *Delete duplicates from the list* |
| Send tracks to Traktor | Drag them onto a deck or playlist |

## Keyboard

| Keys | Does |
|---|---|
| ++ctrl+1++ | The List |
| ++ctrl+2++ | The similarity map |
| ++ctrl+shift+f++ | Search by description in its own window |
| ++del++ | Remove selected tracks from the list |

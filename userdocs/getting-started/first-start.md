# First start

A fresh install starts with an **empty library**. Three steps get you going.

## 1. Add your music

- **Import → Add folder (with subfolders)…** and pick your music folder, or
- drag MP3, WAV and FLAC files or whole folders onto the window.

SongSelector reads each file's tags (artist, title, key, BPM, genre…). Tracks stay where they are on disk: the app
only remembers where they are.

<!-- screenshot: Import menu -->

## 2. Connect your DJ software

If you use Traktor, Rekordbox or Mixxx, SongSelector usually **finds its library by itself** at start-up. Your
DJ software's key, BPM, colours, ratings and playlists then appear in the app, and changes you make there come in
after it saves. See [Connect your DJ software](../dj-software/index.md) for what is read from each program and
what to do if it is not found.

## 3. Set your master tempo

Type the tempo you are playing at into **Master tempo** above the List. Every track's key is shown *at that
tempo*, so you can see at a glance what mixes in key. More in
[Keys at the master tempo](../using/key-and-tempo.md).

## Optional: the sound-based features

The similarity map, closest matches and search by description need audio models (a separate download of up to
1.7 GB). Everything else works without them. See [Getting the models](../sound/models.md).
